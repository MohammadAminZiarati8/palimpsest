# 07 Gear — Decided
> Read when: gear slots, upgrade, merge, dismantle. Numbers → `balancing.md`.

## Slots
| Slot | Who can wear | Main stat |
|---|---|---|
| Weapon | Class-locked (CLS-2) | Attack |
| Armor | Open (Q-12) | Defense |
| Helmet | Open (Q-12) | HP |
| Accessory | Open (Q-12) | Speed, Crit or Accuracy (per item) |

## Items
- **GEAR-1** Every item is pre-designed with fixed stats: 1 main stat + fixed substats. No random stats.
- **GEAR-2** Items for the same class/slot have different focuses, not a single best-in-slot (e.g. crit axe vs steady axe vs lifesteal axe).
- **GEAR-3** Gear rarity: Rare (Blue) → Epic (Purple) → Legendary (Gold). No Common gear.
- **GEAR-10** Number of substats depends on rarity. Proposed: Rare 1 · Epic 2 · Legendary 3.

## Upgrading (Level + Rank, mirrors champions)
- **GEAR-4** Level up with gold + Upgrade Stones. Small stat gain per level. Always succeeds.
- **GEAR-5** Rank up (merge) by consuming 1 copy of the **same item**. Big stat boost + higher max level. Max ★5.
- **GEAR-6** Forge Stone (rare; events, shop) can replace the duplicate in a merge.
- **GEAR-7** Legendary weapons have one small passive per weapon type (e.g. Daggers: crits cause Bleed 1 turn; Bow: first attack can't miss; Axe: +10% dmg vs <50% HP; Sword & Shield: start with small shield; Staff: heals remove 1 debuff).

## Sources & disposal
- **GEAR-8** Main source: gear dungeons; each dungeon stage drops a few specific items (targeted farming). Also campaign, events, shop.
- **GEAR-9** Dismantle gives Upgrade Stones and refunds all upgrade materials spent on that item.

## Open
