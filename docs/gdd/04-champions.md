## Rarity
- **CHM-1** Common (Gray) → Rare (Blue) → Epic (Purple) → Legendary (Gold). Names placeholder.
- **CHM-2** Fixed at summon, never changes. Sets base stats and potential.

## Level
- **CHM-3** Main XP source: XP potions (campaign rewards, XP dungeon).
- **CHM-4** Team champions get a small amount of XP from battles.
- **CHM-5** No feeding/sacrificing champions for XP. Stat growth per level depends on class (CLS-3).

## Rank
- **CHM-6** Rank-up costs class-specific rank material + gold.
- **CHM-7** Each rank raises max level by 10 (Rank 1 = max 10).
- **CHM-8** Each rank-up gives a stat jump.
- **CHM-9** No sacrificing champions to rank up. Rank-up requires current max level (Proposed).

## Skills (Hybrid model)
- **CHM-10** Ranking up upgrades skills; every player gets stronger skills by playing.
- **CHM-11** Awakening adds an extra "Awakened" bonus on top of a skill (AWK-5, AWK-6).
- **CHM-12** No skill-upgrade currency. No random skill-ups.
- **CHM-13** Skill levels mix number upgrades and new effects (e.g. L3 adds Bleed, L4 cooldown −1).
- **CHM-14** Which ranks upgrade which skills: Open (Q-07).
- **CHM-15** No Ultimate skills. All champion skills are normal skills.
