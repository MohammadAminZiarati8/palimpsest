# 06 Classes — Decided
> Read when: class rules. Names are placeholders (Q-01).

| Class | Job | Main stats | Weapon family |
|---|---|---|---|
| Guardian | Tank, protects team | HP, Defense | Shield + one-hand |
| Warrior | Melee damage, can take hits | Attack, HP | Heavy melee |
| Assassin | Single-target burst | Attack, Crit | Light blades |
| Ranger | Ranged single-target, precise (D-34) | Attack, Accuracy | Bow, crossbow, thrown |
| Support | Heal, buff, debuff | HP, Speed | Focus (staff, tome, lantern…) |
| Mage (D-24) | Ranged area magic (Splash/Row) + status effects; fragile (D-34) | Attack, Speed (D-35) | Arcana (wand, orb, rod, scroll) (D-36) |

- **CLS-1** Exactly these 6 classes (Mage added, D-24). Mage has no room option for now; revisit after the demo (D-37).
- **CLS-2** Weapon must match class (by weapon family, CLS-7).
- **CLS-3** Each class has its own automatic stat growth per level (demo placeholder: BAL-8, D-55).
- **CLS-4** Each class has its own rank material (e.g. Guardian Badge).
- **CLS-5** Campaign stages may have class requirements (CMP-P2).
- **CLS-6** Not included: class counters, team class limits, class team bonuses.
- **CLS-7** Weapon *families* instead of single weapons, so legends keep their iconic arms: Guardian = shield + one-hand · Warrior = heavy melee (axe, greatsword, mace) · Assassin = light blades · Ranger = bow, crossbow, thrown · Support = focus (staff, tome, lantern, instrument) · Mage = arcana (wand, orb, rod, scroll). Weapon gear stays class-locked (CLS-2).
- **CLS-8** Keep these class names (clear to players in any setting).
