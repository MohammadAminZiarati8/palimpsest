# 03 Campaign
> Read when: campaign, stages, stars, chapter rewards.

## Decided
- **CMP-1** No energy system. Stages can be replayed freely.
- **CMP-2** Each stage result: 1, 2 or 3 stars. Rewards depend on stars earned.
- **CMP-3** Each chapter has a bigger reward. Model is Open (Q-05).
- **CMP-4** Campaign cannot be finished in one day; progress requires stronger champions.
- **CMP-5** Good tactics can push further than raw power (pillar 3).
- **CMP-6** One-time content: once all stars are collected it is finished. Repeatable farming = Dungeons.
- **CMP-7** Champion reward for 3-starring every stage (example of mission reward, OVR-5).

## Proposed (not final)
- **CMP-P1** 3-star conditions are tactical, e.g. "no champion dies", "win within X turns" (Q-06).
- **CMP-P2** Some stages have class requirements, e.g. "≥1 Support", "no Guardians".
- **CMP-P3** Enemy types that reward classes: shielded → Warrior; back-row healer → Assassin/Ranger; hard-hitting boss → Guardian.
- **CMP-P4** One Legendary set piece as an early chapter reward (only if sets approved, Q-11).

## Implementation notes
- Star result per stage = best ever (stars never go down). Rewards per star tier are granted once (first time each tier is reached). — Proposed
- Stage definitions (enemies, conditions, requirements, rewards) are content data → `tech/data.md`.
