# Demo definition — Decided (D-28..D-33)
> Read when: planning or building the demo. Roadmap checkpoint: demo = M0–M2 + a slice of M3/M4 (D-13). Keep it small (D-15).

## Goal
- **DEMO-1** Answer one question: *is the room-by-room combat fun?* (stealth vs fight choice, party size, lines). Everything else is minimal.

## Content
- **DEMO-2** Prologue (1–2 fights) + **Seedbed** chapter (~6 stages, config). About 30–45 min of play. No Thousand Nights in the demo (D-28).
- **DEMO-3** Enemies: the 5 demo Censors (D-15), Seedbed reskin. No boss (Editor captain ends the Seedbed).
- **DEMO-4** Roster: 4 champions (D-29, D-38):
  | Joins | Slot | Class |
  |---|---|---|
  | Prologue start | Starter 1 — **main hero** (Unwritten) | Warrior |
  | Prologue start | Starter 2 (Unwritten) | Assassin |
  | Prologue end | Tutorial Recall — **Lady White Snake** (D-48, D-49, may change) | Support |
  | Seedbed end | Rescued hero (Unwritten) | Mage |
  - Guardian is out of the demo (its rear-guard job is taught in Thousand Nights ch1).

## Systems in
- **DEMO-5** Combat: everything taught up to the Seedbed (lines, party + Noise, room options, Rewrite, Herald, Notice, intents, Exposed). **No auto-battle** in the demo (D-33).
- **DEMO-6** Stars per stage (3 = nobody Down) and replay.
- **DEMO-7** Champion level up (XP from stages) + rank up (class materials from stages), placeholder numbers (GDD-5). Skills fixed at base level; no gear, no awakening (D-30).
- **DEMO-8** Tutorial Recall only: one scripted summon, no banners, no currency.
- **DEMO-12** Real art, not placeholders (D-68..70): 4 heroes + demo Censors as cut-out sprites, Seedbed/Prologue room backgrounds, UI. Rules `art/style.md`.
- **DEMO-9** Online (D-31): guest login, progress saved on the server, server re-checks stage results (slice of M3/M4).

## Systems out (after the demo)
Auto-battle · Gear · Awakening / Soul Stones · real summoning · Dungeons · events · shop · IAP / ads (D-12: no purchases in first build) · chapter rewards (Q-05) · extra roles and bosses.

## Platform & testers
- **DEMO-10** Android, landscape (D-12). English only. Tester = the user only, for now; install the APK directly on their phone, no Google Play yet (D-32). More testers later.
- Server for the demo can run on the user's own PC or a free tier (stack: Q-03).
- **DEMO-11** After the demo: decide launch scope Q-20, roster, currencies Q-13 (D-13).
